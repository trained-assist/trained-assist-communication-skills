# ADR-0001: Один handler на метод, несколько дверей; своя лестница моделей запрещена

Status: Accepted · 2026-10-02 · Обновлён 2026-10-03 (рантайм Worker) · Обновлён 2026-10-04 (второй метод, issue #10) · Эпик: trained-assist/trained-assist-communication-skills#1

## Контекст

Сервис должен обслуживать два типа потребителей: MCP-хост (через `generate_next_message_to_conversation_partner`) и доменные адаптеры (сейчас рекрутинг; далее sales и другие домены). Уже есть ревью контракта (trained-assist-agent-architecture#125): один метод, общий retry budget, `model_profile` только по allowlist, PII-телеметрия.

Второй метод, `resolve_user_intent` (issue #10), сделал первое правило неоднозначным: «один handler» при двух методах можно прочитать как «один handler на всё». Прочитать его так — значит получить две независимые бизнес-логики в одном домене, чего ADR и не хотел.

## Решение

1. **Один handler на метод.** Вся логика генерации и guard'а writer'а живёт в одном месте (`src/handler.mjs`), вся логика resolver'а — в другом (`src/intent-handler.mjs`). Общими у них остаются только примитивы без доменного смысла: класс ошибки и PII-free логгер (`src/typed-error.mjs`), клиент лестницы (`src/ladder.mjs`) и MCP-разговор. Два метода — две прикладные функции; один метод — одна функция.
2. **Дверей несколько, логика одна.** `src/mcp/protocol.mjs` — чистая функция «JSON-RPC сообщение → ответ», без какого-либо I/O. Её драйвят:
   - `src/index.mjs` — Cloudflare Worker: `POST /mcp` (streamable HTTP), `POST /v1/dialogs/next-message` и `POST /v1/intents/resolve` (REST-лица тех же handler'ов, issue #6 §1 и issue #10 §1);
   - `src/mcp/entrypoint.mjs` — stdio-дверь для локальной песочницы и `node --test`.
   Соответствие «имя инструмента → функция» живёт в одном месте (`src/mcp/registry.mjs`) и одинаково для всех дверей: пока инструмент был один, отображение было неявным (`deps.generate`), и оно стало молчаливо неверным в день, когда инструмент стал вторым. Логика, добавленная в одну дверь и не в другую, — это вторая реализация, ровно то, что запрещает данный ADR.
3. **Своя лестница запрещена.** Выбор модели — только общий `trained-assist-llm-ladder` (ladder `conversation`). Никаких собственных конфигов моделей, ключей и fallback-цепочек: это дублирование, которое потом никто не обслуживает. Issue #10 §7 предлагал Workers AI как классификатор — отклонено по этому же пункту: общая лестница уже является Worker'ом, второй владелец конфигурации моделей не появляется.
4. **Рантайм — Cloudflare Worker, не VM.** VM на GCP выводится из эксплуатации (agent#2053, решение владельца 03.10.2026). stdio MCP-сервер не переживёт это: stdio означает локальный дочерний процесс. Поэтому метод живёт в Worker'е и говорит по HTTP, а лестница уже является Worker'ом — путь запроса Worker→Worker, VM в нём нет.
5. **Stateless намеренно.** Нет D1/Vectorize/AI-биндинга. Состояние диалога выводится из переданной истории каждый раз; оригинал истории остаётся источником истины, а не кэш рядом с ним. База понадобится только при измеренной потребности в кэше — вводить её заранее значит платить за миграции, авторизацию и второго владельца durable-state без причины.

## Последствия

- Плюс: одна точка правды по guard'у/бюджету попыток на метод — общий retry budget не перемножается между адаптером, MCP и лестницей.
- Плюс: песочница и CI проверяют ровно тот путь, который уйдёт в прод (stdio JSON-RPC и HTTP-контракт лестницы).
- Плюс: метод не зависит от VM и переживает её вывод из эксплуатации.
- Плюс: добавление второго метода не потребовало ни новой двери, ни нового протокола — только один handler и одна строка в реестре.
- Минус: изменение контракта требует синхронного обновления схем, фикстур и потребителей.
- Минус: Worker-рантайм не даёт произвольных файлов и долгих процессов — длинная история обрабатывается за один вызов, а не фоновой задачей.
- Минус: «один handler» теперь читается как «один handler на метод». Формулировка уточнена здесь именно потому, что неоднозначность стоила бы второго расхождения реализаций.
- Риск: логика, добавленная только в одну дверь, ломает инвариант — CI и песочница падают, это и есть защита.
